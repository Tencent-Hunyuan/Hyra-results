Fix an integer n >= 3. All integrations on spheres use Euclidean surface measure. We construct the angle first and then verify the moment and critical-point assertions.

1. An exact smooth phase cancellation.

Put w(t) = (1-t^2)^((n-1)/2) for -1 <= t <= 1, and put A = integral_0^1 w(t) dt. The weight is even, continuous on [-1,1], strictly positive on (-1,1), and smooth on (-1,1); A is finite and positive. Define
B(u) = A^{-1} integral_0^u w(t) dt, 0 <= u <= 1.
Then B is a continuous strictly increasing bijection from [0,1] onto [0,1], is smooth for 0 <= u < 1, and satisfies B'(u) = w(u)/A.

We give a smooth real phase beta on [0,1] whose complex exponential has zero unweighted integral and which is constant near the endpoints. For a concrete smooth cutoff, let eta(v) = exp(-1/v) when v > 0 and eta(v) = 0 when v <= 0. This function is smooth: on the positive side every derivative is a polynomial in 1/v times exp(-1/v), hence tends to zero as v decreases to zero. Define
chi(v) = eta(v-1/4) / (eta(v-1/4) + eta(3/4-v)).
The denominator is positive for every real v. Thus chi is smooth, equals 0 for v <= 1/4, and equals 1 for v >= 3/4. On [0,1/2] put q(s) = pi chi(2s). In particular q = 0 on [0,1/8] and q = pi on [3/8,1/2]. Set
beta(s) = q(s) for 0 <= s <= 1/2,
beta(s) = pi + q(s-1/2) for 1/2 <= s <= 1.
The two definitions equal the constant pi on their respective neighborhoods of 1/2, so beta is smooth at the join. It is identically 0 near 0 and identically 2*pi near 1. Extend beta by these constants outside [0,1], obtaining a smooth function on R. The defining identity
beta(s+1/2) = beta(s)+pi, 0 <= s <= 1/2,
implies
integral_0^1 exp(i beta(s)) ds
= integral_0^{1/2} [exp(i beta(s)) + exp(i beta(s+1/2))] ds
= 0,
where i is the imaginary unit.

For |t| <= 1 define alpha_n(t) = beta(B(|t|)), and for |t| >= 1 define alpha_n(t) = 2*pi. Let a_n and b_n be the unique points of (0,1) satisfying B(a_n) = 1/8 and B(b_n) = 7/8. Strict monotonicity gives a_n < b_n. The plateau properties of beta give alpha_n(t) = 0 when |t| <= a_n and alpha_n(t) = 2*pi when |t| >= b_n. On each open interval not meeting 0 or the points +/-1, the definition is a composition of smooth functions. At 0 it is locally the constant 0, and at +/-1 it is locally the constant 2*pi. Thus alpha_n is a smooth even real function on all of R. This argument does not require the weight w to be smooth at +/-1.

Evenness of w and alpha_n, followed by the change of variable s = B(t), gives
integral_{-1}^1 w(t) exp(i alpha_n(t)) dt
= 2 integral_0^1 w(t) exp(i beta(B(t))) dt
= 2A integral_0^1 exp(i beta(s)) ds
= 0.
The substitution is valid since B is continuously differentiable on [0,1], strictly increasing, and has derivative w/A, positive on [0,1). Equivalently it can first be done away from the endpoint and then passed to the limit by continuity. Taking real and imaginary parts, both integral_{-1}^1 w(t) cos(alpha_n(t)) dt and integral_{-1}^1 w(t) sin(alpha_n(t)) dt vanish exactly.

2. The twisted coordinate is a smooth odd height function after a diffeomorphism.

Define an ambient map Psi: R^n -> R^n by
Psi(x)_1 = x_1 cos(alpha_n(x_3)) + x_2 sin(alpha_n(x_3)),
Psi(x)_2 = -x_1 sin(alpha_n(x_3)) + x_2 cos(alpha_n(x_3)),
Psi(x)_j = x_j for 3 <= j <= n.
It is smooth and preserves |x|. Since the third coordinate is unchanged, its inverse is the smooth map
Psi^{-1}(y)_1 = y_1 cos(alpha_n(y_3)) - y_2 sin(alpha_n(y_3)),
Psi^{-1}(y)_2 = y_1 sin(alpha_n(y_3)) + y_2 cos(alpha_n(y_3)),
Psi^{-1}(y)_j = y_j for 3 <= j <= n.
The formulas multiply inverse planar rotation matrices at the same third coordinate, proving both inverse identities. Therefore Psi restricts to a smooth diffeomorphism of S^{n-1}. Since alpha_n is even, Psi(-x) = -Psi(x). If h(y) = y_1 on S^{n-1}, then F_n = h composed with Psi. This proves that F_n is smooth and odd, including at the points with x_3 = +/-1.

The tangential gradient of h is e_1 - y_1 y. It vanishes if and only if y = e_1 or y = -e_1: its vanishing implies e_1 = y_1 y, and taking norms gives |y_1| = 1. For every x, the tangent derivative of Psi is an isomorphism; the chain rule consequently says that x is a critical point of F_n exactly when Psi(x) is a critical point of h. As alpha_n(0) = 0, Psi fixes e_1 and -e_1. Hence those are exactly the two critical points of F_n.

In fact F_n equals h on the open spherical strip |x_3| < a_n, containing both e_1 and -e_1. In local coordinates v in e_1 perpendicular, the sphere near +/-e_1 is parametrized by v -> +/-sqrt(1-|v|^2)e_1 + v. The metric at v=0 is the Euclidean inner product on e_1 perpendicular. The coordinate expression for h is +/-sqrt(1-|v|^2), whose first derivative at 0 is zero and whose second derivative there is respectively minus or plus that inner product. At a critical point the coordinate second derivative equals the intrinsic Hessian. Thus Hess F_n(e_1) = -g_{e_1} and Hess F_n(-e_1) = g_{-e_1}, which are nonsingular.

3. All first spherical moments vanish.

Write I_j = integral_{S^{n-1}} x_j F_n(x) d sigma(x). The reflection changing only the sign of x_1 preserves sigma and x_3, and the reflection changing only the sign of x_2 has the same properties. For j >= 3, apply the first reflection to the summand x_j x_1 cos(alpha_n(x_3)) and the second to the summand x_j x_2 sin(alpha_n(x_3)). Each integrand changes sign under its specified reflection. Thus I_j = 0 for j >= 3. The mixed products in the first two moments vanish by these reflections as well, leaving
I_1 = integral_{S^{n-1}} x_1^2 cos(alpha_n(x_3)) d sigma(x),
I_2 = integral_{S^{n-1}} x_2^2 sin(alpha_n(x_3)) d sigma(x).

For completeness, slice the sphere by t = x_3. Let S(E) be the unit sphere in E = e_3 perpendicular, an (n-1)-dimensional Euclidean space. Away from the two poles the parametrization is
(t,y) -> sqrt(1-t^2)y + t e_3, -1 < t < 1, y in S(E).
If r = sqrt(1-t^2), tangent lengths in the y directions scale by r, in n-2 dimensions. The t derivative is -t y/r + e_3, is perpendicular to the y derivatives, and has length 1/r. Thus the surface element is r^(n-3) dt d sigma_E(y). The two omitted poles have zero surface measure. Moreover x_1 = r y_1 and x_2 = r y_2. By invariance of sigma_E under coordinate permutations within E, the integrals of the n-1 coordinate squares y_j^2, j != 3, are all equal. Their sum is the integral of |y|^2 = 1. Consequently
integral_{S(E)} y_1^2 d sigma_E(y) = integral_{S(E)} y_2^2 d sigma_E(y) = |S^{n-2}|/(n-1),
where |S^{n-2}| is the surface area of the unit sphere in R^{n-1}. It follows that
I_1 = [|S^{n-2}|/(n-1)] integral_{-1}^1 (1-t^2)^((n-1)/2) cos(alpha_n(t)) dt,
I_2 = [|S^{n-2}|/(n-1)] integral_{-1}^1 (1-t^2)^((n-1)/2) sin(alpha_n(t)) dt.
Both integrals vanish by Step 1. Along with the already proved identities for j >= 3, this establishes integral x F_n d sigma = 0. All assertions follow.
